# ADR 0007: アクセス分析は自前のクリック計測 +（任意）Cloudflare Web Analytics / 접속 분석

状態 / 상태: 採用 / 채택 (2026-10)

## 決定 / 결정
- **電話・道案内・カカオのボタンのクリック数**を `click_events` に保存（種類・言語・ページ名・時刻のみ）。Cookie・IP・端末情報は保存しない。管理画面ダッシュボードに直近30日の件数を表示。
- ページ閲覧数は、独自ドメインを取得して Cloudflare を前に置く場合に Cloudflare Web Analytics（無料・Cookie なし）を任意で有効化できる。DuckDNS の間は使えない（`docs/runbook.md`）。

## 理由 / 이유
目的は「電話してもらえたか」。個人情報を扱わなければ同意バナーが不要で、高齢の利用者にも優しい。Google Analytics は設定が重く、同意管理が必要になる。

## 注意 / 주의
サーバーが受けるのは件数だけ。ボット等で水増しされうるため、あくまで目安として使う。
