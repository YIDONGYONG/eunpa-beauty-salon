# 은파미용실 홈페이지

어머니가 운영하는 동네 미용실 "은파미용실"의 공식 홈페이지입니다.
**비개발자인 원장님이 가격표와 블로그를 직접 수정**할 수 있고, 새로 찾는 손님이 방문 전에 가격과 원장님 경력을 확인할 수 있도록 만들었습니다.

> 상태: 개발 약 95% 완료 / **아직 배포 전**
> 개발: 기획·디자인·개발·문서 모두 1인, 약 10일

## 1. 만든 이유

어머니의 미용실은 단골과 지인 소개로 손님이 옵니다. 그런데 인터넷에 검색하면 주소만 나오고, 가격이나 시술 내용 같은 자세한 정보를 찾을 수 없었습니다. 신규 손님을 늘리려면 방문 전에 판단할 재료를 주는 것이 먼저라고 생각했습니다.

- 실제 사용자(원장님)가 있는 프로젝트입니다.
- 목적: 신규 고객 확보, 지역 주민에게 알리기, 기존 단골에게 유용한 정보(블로그) 제공
- 기획 내용은 [docs/planning.md](docs/planning.md)에 정리했습니다.

## 2. 주요 기능

- 홈, 미용실 소개(원장 경력 30년 이상), 블로그, 찾아오시는 길
- 가격표 공개, 관리자가 가격과 메뉴를 직접 수정 【TODO】 실제 구현 방식(인라인 편집 등) 확인
- 블로그 작성·수정 (Action Text), 대표 이미지 업로드 (WebP 자동 변환, 긴 변 1600px 이하)
- 네이버 지도 연동 (키 미설정 시 지도 이미지로 대체), 네이버 예약·네이버 플레이스 연결 【TODO】 실제 링크 위치 확인
- 구조화 데이터(JSON-LD), 모바일 최적화

**의도적으로 만들지 않은 것**: 예약 기능과 후기 기능. 개인정보 취급과 운영 부담을 피하기 위해 네이버 예약·네이버 플레이스와 연동합니다.
